=== PASOS PARA EL INTEGRANTE 3 ===

1. En tu PC, abre la consola en la carpeta de tu repositorio (tp-final-wollok-game-tercerafila).
2. Trae los cambios que subió el Integrante 2 ejecutando:

   git pull

3. Copia los archivos de esta carpeta ('obstaculos.wlk', 'heroes.wlk', 'defensores.wpgm') y pégalos en tu repositorio.
4. Ejecuta:

   git add .
   git commit -m "feat: implementar obstaculos y validacion de limites espaciales"
   git push

5. Avisa al Integrante 4 para que continúe.
