=== PASOS PARA EL INTEGRANTE 1 ===

1. En tu PC, abre la carpeta de tu repositorio de GitHub de la facultad (tp-final-wollok-game-tercerafila).
2. Copia los archivos 'personajes.wlk' y 'defensores.wpgm' de esta carpeta y pégalos en la carpeta del repositorio.
3. Asegúrate de que estén los assets (imágenes en la carpeta assets).
4. Abre la consola en la carpeta del repositorio y ejecuta:

   git add .
   git commit -m "feat: configurar tablero y movimiento basico del heroe"
   git push

5. Avisa al Integrante 2 para que continúe.
